Documentation: tsv_headers.py

Purpose
-------
This script processes TSV (Tab-Separated Values) files and allows users to:
- Extract the full header row.
- Filter headers based on a case-insensitive keyword match.
- Limit the number of displayed columns based on the filtered result.
- Output matching columns and their values to STDOUT.
- Send all warnings and errors to STDERR for clean separation.

Useful for data analysis, pre-processing, and batch scripting where quick column filtering from tabular data is needed.

Variable & Argument Overview
----------------------------
- args.input        : Path to the input .tsv file. This is a required argument.
- args.search       : Optional string to match against header names (case-insensitive).
- args.number       : Optional integer to limit the number of headers returned after filtering.
- headers           : List of column names extracted from the first row of the file.
- matched_headers   : Subset of headers after applying the keyword filter and limit.
- indices           : Index positions of selected headers, used for column slicing.
- reader            : CSV reader configured for tab-delimited files.
- writer            : CSV writer configured to output tab-delimited lines to STDOUT.

Troubleshooting Recommendations
-------------------------------
Problem                                  | Recommendation
----------------------------------------|------------------------------------------
FileNotFoundError or similar            | Ensure the path passed to --input exists and is a regular file.
PermissionError                         | Check file permissions and ensure you have read access.
TSV file is empty                       | The file must have at least one row (the header).
No headers match the keyword            | Try relaxing the search keyword or verify header naming.
missing some expected columns           | Some rows may be shorter than expected; the script will skip them and print a warning.
The number of columns must be > 0       | Use a value of at least 1 with --number.
